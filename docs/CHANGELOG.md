# 更新日志

## v1.0.0（2026-10-25）· 原型首个版本

### 新增功能

**AI 导诊智能体**
- 多轮口语化问诊，逐步收集症状
- 基于本地知识库的 RAG 检索（7 条导诊知识）
- DeepSeek Function Call 工具编排：科室 → 医生 → 排班 → 预约
- 急重症关键词前置拦截（约 30 个口语化表述，不依赖模型）
- 无 API Key 时自动回退规则引擎，功能完整可演示

**AI 前台客服**
- 20 条知识库条目，覆盖门诊信息 / 科室信息 / 就诊指南 / 医保服务 / 检查与体检 / 常见问题
- **每条回答标注来源**，并区分「已核实 / 未核实」
- 检索不到时明确回答"知识库暂未收录"，引导官方渠道，不编造事实
- 值班医生走实时排班查询（工具调用）
- 泛化关键词过滤 + 相关性阈值，避免无关问题误匹配

**校园健康知识库**
- 24 条科普主题，10 个分类
- 每条包含：常见表现 / 预防措施 / 自我照护 / 何时就医
- 长关键词优先的检索权重（如"咳嗽两周"命中肺结核）

**预约挂号**
- 号源余量展示与进度条
- 原子条件扣减防超卖（`UPDATE ... WHERE remain > 0`）
- 部分唯一索引防重复预约
- 幂等取消与号源回滚
- 越权访问拦截（403）

**就诊评价**
- 整体星级 + 四个维度评分（服务态度 / 候诊时间 / 沟通解释 / 就诊环境）
- 文字评价（300 字）+ 匿名选项
- 一人一评（数据库唯一约束）
- 医生评分聚合，评价内容公开可见

**账号与会话**
- 密码加盐哈希（SHA-256 + 每用户独立 salt）
- Bearer Token 会话
- 单设备登录：新登录使旧会话失效（会话互斥）
- 前端心跳（15s）+ 页面可见性校验，及时发现被挤下线

### 数据

- 14 个真实科室（来源：郑州大学医院官网）
- 9 位真实医生（姓名/职称/擅长，来源：官网专家介绍）
- 8 位补全医生（模拟，标注 `source=mock`）
- 238 条模拟排班
- 5 个演示学生账号
- 8 条演示评价（可用于展示评价页面）

### 测试

- `smoke_test.py`：28 项端到端自检
- `test_concurrent.py`：并发抢号压测（20 线程抢 1 号 → 1 成功 / 19 冲突）

### 部署

- 本地 / 局域网运行
- Cloudflare Tunnel 固定域名 + 自动 HTTPS
- 静态资源 no-cache 中间件，避免移动端缓存旧版本

### 已知限制

- 排班时间、医保比例、门诊时间为演示数据，未与官方核对
- 无管理端（号源维护、核销、统计看板待开发）
- SQLite 单文件适合原型，生产需换 PostgreSQL
