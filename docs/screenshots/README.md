# 界面截图

本目录用于存放 README 里展示的界面截图。

## 需要拍的 3 张（手机端竖屏最佳）

| 文件名 | 拍什么 | 建议内容 |
|---|---|---|
| `home.jpg` | 首页 | 显示「AI 导诊」「服务咨询」「就诊口碑」「校园健康知识」四张卡片 |
| `service.jpg` | AI 客服对话 | 问「今天谁值班」或「医保能报多少」，要能看到**来源标注** |
| `health.jpg` | 校园健康知识 | 搜索「发烧」后的结果列表，或某个条目详情页 |

## 拍摄建议

1. **用手机浏览器**打开 `https://zzu-xiaoyitong.top/app/`（不要用微信内置浏览器）
2. 登录 `2025010001` / `zzu123456`
3. 截图后**裁剪掉状态栏**（时间、电量那些），只保留页面内容
4. 宽度控制在 800–1200 px，文件大小 < 500 KB（避免仓库过大）
5. 文件名必须是：`home.jpg`、`service.jpg`、`health.jpg`（区分大小写）

## 放到这里之后

README 首页的「界面预览」表格会自动显示这三张图（链接已配好）。

然后提交：

```powershell
cd F:\zzu-hospital
git add docs/screenshots
git commit -m "docs: 添加界面截图"
git push
```
